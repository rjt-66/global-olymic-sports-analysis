# 🏅 Global Olympic Sports Analysis

## 📌 Project Overview

Global Olympic Sports Analysis is a data analytics project focused on exploring Olympic sports, medal performance, and sporting history through data visualization.

This project combines Tableau dashboard analysis with a responsive website built using HTML, CSS, and JavaScript. The website provides an easy way to access the project workbook and understand its objectives.

## 🎯 Project Objectives

- Analyze Olympic sports and medal performance.
- Explore differences in sporting achievements across countries.
- Understand patterns in Olympic history using data visualization.
- Present the project through a simple, user-friendly website.
- Integrate the project website with GitHub Pages.

## 🚀 How to Use the Project

1. Open the project website.
2. Click the Dashboard link to access the workbook on Google Drive.
3. Download the Tableau workbook if required.
4. Open the `.twbx` file using compatible Tableau software.
5. Explore the available charts, filters, and visualizations.

## 💻 Run the Website Locally

1. Download or clone this GitHub repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.

## 🌍 Deployment Using GitHub Pages

1. Upload the project files to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/(root)` folder.
5. Click **Save**.
6. Open the published website URL after deployment completes.
